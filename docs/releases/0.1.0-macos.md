# YourMove 0.1.0 — macOS release notes (draft)

**Status:** Locally verified release candidate; **not yet a published, notarized installer**. Proposed first invited-beta readiness review: **November 6, 2026**, with earlier release allowed if every applicable gate passes. This date is not a promise of download availability.

## What YourMove does

YourMove helps job seekers organize opportunities and application materials, prepare employer forms, and keep records of applications they personally complete. The desktop application runs locally and preserves the applicant's review and submission authority.

### Included workflows

- Save and prioritize job opportunities and available posting details.
- Manage PDF/DOCX resumes and select the appropriate document for each job.
- Maintain approved candidate information, prepared application answers, and reusable writing references.
- Create, edit, and save cover letters with optional AI assistance where configured.
- Open selected employer applications and, on qualified forms, explicitly authorize supported field/document filling.
- Record completion after the applicant independently submits on the employer website.

**YourMove does not automatically submit applications.** Form filling and attachment selection do not prove that an employer received a submission.

## System requirements

- Apple Silicon (arm64) Mac running **macOS 26 or later**.
- Compatible installed Chrome/Chromium for assisted employer-form operations; not required for basic local organization.
- Internet connectivity for posting retrieval and external AI providers, when those actions are requested.
- An AI provider is optional.

Intel Macs, earlier macOS, Windows, and Linux desktop releases are not qualified for 0.1.0. Employer compatibility varies by platform, form step, and control. Supported posting metadata does not imply supported application filling.

## Local data and privacy

By default, saved data lives in `~/Library/Application Support/YourMove`. Back up the entire workspace, including `jobs.db` and stored `resumes/`, with the application closed. `YOURMOVE_DATA_DIR` can select another absolute location. Active employer-browser sessions are not restored after restart, though saved local materials persist.

Explicit external AI actions may transmit the authorized resume/job context to the chosen provider; installing YourMove does not require an AI connection.

## Mac release status

The first macOS packaging PR was merged October 23, 2026. Local build and acceptance work on macOS 26.5.2/arm64 passed, and CI builds and verifies the ad-hoc-signed branded `.app`. The release tools generate a binary ZIP, corresponding source ZIP, and checksums locally.

**Still pending:** Candidate-specific synthetic workflow acceptance, supported employer-form qualification, frozen artifact decision, and a browser-downloaded installation test. For a normal public download experience, Developer ID signing and Apple notarization are also pending. No public download is represented as available until an actual release is published.
