# YourMove v0.1.0 — macOS Technical Alpha

**Release classification: SHIP RESTRICTED (owner-approved November 5, 2026).** This is an early, unnotarized Apple Silicon build for technically comfortable testers. It is not a conventional Apple-verified installer. Publishing this document alone does not publish the app.

## What it does

YourMove helps job seekers organize opportunities, manage resumes and application materials, prepare employer forms, and record applications they personally submit.

- Save and prioritize job opportunities and posting details.
- Import and associate PDF/DOCX resumes with opportunities.
- Maintain candidate information, saved answers, and reusable writing.
- Write and save cover letters; use optional AI assistance only when configured and explicitly authorized.
- Open application pages and explicitly request supported field/document filling. Manually complete unsupported fields.
- Record a completed application after submitting on the employer website yourself.

**YourMove never automatically submits employer applications.** Successful filling does not establish employer receipt or completion.

## Requirements and known limits

- **macOS 26 or later, Apple Silicon (arm64)**. Intel, older macOS, Windows, and Linux are not supported in this release.
- An installed compatible **Chrome/Chromium** browser is required for assisted application-form operations; local organization works without it.
- Browser assistance has passed controlled fixture tests, not a broad live employer ATS qualification. Expect manual correction and fallback. Safari/WebKit employer-browser support is not offered.
- The Firefox option has passed controlled fixture tests but depends on a supported executable being available. Do not assume it works on a clean Mac without browser setup.
- Career Discovery and Career Studio are not part of this release. AI services are optional and may require separate credentials and explicit consent.
- No built-in automatic updates. Replace the app manually only after backing up local data and checking the next release's guidance.

## Installing an unnotarized alpha

1. Download the **unnotarized macOS arm64 ZIP** from the GitHub Release assets, and compare its SHA-256 with the published checksum.
2. Extract the ZIP with Finder and place `YourMove.app` in Applications.
3. Try to open the app. Because this build is **ad-hoc signed and not notarized**, macOS may block initial launch.
4. If you trust the verified download, use **System Settings → Privacy & Security → Open Anyway** when macOS offers that per-app approval. Follow the on-screen confirmation. Do **not** disable Gatekeeper globally or strip quarantine attributes.

If your Mac does not offer an individual approval path, or the app still cannot open, report the exact macOS message. Do not bypass system security.

## Local data and privacy

User data is stored by default under `~/Library/Application Support/YourMove`. With YourMove completely closed, back up the **entire directory**, including `jobs.db` and `resumes/`, not the database alone. In-progress employer-browser sessions are not resumed after app restart.

Actions that retrieve employer pages or request an external AI provider may transmit selected information. They are separate from normal local organization and should require the applicant's authorization.
