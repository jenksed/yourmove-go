# YourMove 0.1.0 — macOS

Status: Release candidate. Public distribution is pending.

## About this release

YourMove is a local-first application assistant for job seekers.
It reduces repeated preparation work while leaving review and
application submission decisions with the applicant.

This is the initial macOS desktop release target.

## Capabilities

- Save and organize job opportunities.
- Import and organize PDF and DOCX resumes.
- Select different resumes for different applications.
- Maintain candidate information and reusable application answers.
- Prepare, edit, and save cover letters.
- Use optional configured AI providers for supported writing tasks.
- Inspect and fill supported employer-form controls after an
  explicit applicant action.
- Record completed applications after the applicant confirms
  submission on the employer's website.

YourMove never automatically submits an employer application.

## System requirements

- Apple Silicon Mac (arm64).
- macOS 26 or later.
- Installed compatible Chrome/Chromium for employer-form assistance.
- Internet access for job-source checks and external AI providers,
  when those features are requested.

An AI connection is optional. Basic organization and saved-document
management work without one.

Intel Macs, older macOS releases, and Windows/Linux desktop
installation are not qualified for this version.

## Data and privacy

YourMove stores its application data locally.

Default macOS workspace:

    ~/Library/Application Support/YourMove

Backups must include the entire workspace, including jobs.db
and the resumes directory.

An external AI provider may receive selected resume and job context
only when the applicant authorizes the applicable generation action.

## Important limitations

- Assisted employer-form support is limited to qualified controls
  and workflows; it does not guarantee universal ATS compatibility.
- Employer websites may change independently of YourMove.
- Active employer browser sessions are not restored after app exit.
- Filling a field or choosing an attachment is not proof that an
  employer has accepted or received an application.
- Final submission remains the applicant's responsibility.
