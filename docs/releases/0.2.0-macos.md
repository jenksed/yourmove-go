# YourMove v0.2.0 — macOS Technical Alpha

**Build 5 release candidate: owner acceptance and publication pending.** The existing public build 4 remains the approved unnotarized macOS technical alpha until the owner authorizes a correction. Windows assets remain held back pending Windows 11 native acceptance.

## What it does

YourMove is a local-first Mac workspace for working through job applications: opportunities, résumés, answers, cover letters, and records of what you personally submitted.

- Save and prioritize job opportunities; supported sources (including repaired Ashby and Workday intake) fill in posting details.
- Import and associate PDF/DOCX résumé versions with opportunities, with role-family routing.
- Maintain candidate information, an approved Answer Library, and reusable career evidence.
- Write and save cover letters; use optional AI assistance only when configured and explicitly authorized.
- Review the employer form in context and explicitly authorize each supported fill. Manually complete unsupported fields.
- Record a completed application after submitting on the employer website yourself.

**YourMove never automatically submits employer applications.** Successful filling does not establish employer receipt or completion.

## What is new in v0.2.0

- Complete S1–S3 application experience on the React/TypeScript frontend in the same Wails window; Go remains authoritative for validation, state, documents, and effects.
- Ashby metadata intake repair (case-insensitive board match, corporate careers URL support) and Workday posting identity intake repair, covering previously failed records.
- macOS version identity 0.2.0 (build 5).
- Owner-accepted UI polish round on the Opportunities experience.
- The existing macOS updater checks for newer versions in the background. You choose when to install and restart; update archives must pass the pinned signing-key verification.

## Windows status: held back

No Windows installer, executable, or checksum is published with v0.2.0. The Windows x64 NSIS package builds and passes installer-lifecycle qualification in CI (13 PASS, 3 NOT RUN: A/B upgrade, browser Fill, GUI acceptance), but interactive Windows 11 acceptance — window presentation, managed-Chromium Fill, and version-to-version upgrade — has not been performed. Windows publication waits for that acceptance.

## Requirements and known limits

- **macOS 26 or later, Apple Silicon (arm64)**. Intel, older macOS, Windows, and Linux are not supported in this release.
- An installed compatible **Chrome/Chromium** browser is required for assisted application-form operations; local organization works without it.
- Browser assistance has passed controlled fixture tests, not a broad live employer ATS qualification. Expect manual correction and fallback.
- Career Discovery and Career Studio are not part of this release. AI services are optional and may require separate credentials and explicit consent.
- Build 5 can check for newer semantic versions. Build 4 has no configured update channel and requires a manual upgrade. The update channel must be available, the update must be authenticated, and installation and restart require your approval. A writable installed app location is required; otherwise use the manual download.

## Upgrading from v0.1.0 or v0.2.0 build 4

1. With YourMove completely closed, back up the **entire** workspace directory (`~/Library/Application Support/YourMove`), including `jobs.db` and `resumes/`.
2. Install v0.2.0 over the existing application (drag to Applications and replace, or extract the ZIP over it).
3. Reopen the same workspace. Saved opportunities, résumé bytes and associations, answers, letters, history, and settings are preserved; the v0.1.0 → v0.2.0 storage migration was verified on a synthetic fixture (records and bytes intact).
4. Do not merge a `jobs.db` backup with a different `resumes/` directory. Keep the old backup until the upgraded workspace opens and document checks pass.

## Installing an unnotarized alpha

1. Download the **DMG installer** (or the unnotarized macOS arm64 ZIP) from the GitHub Release assets, and compare its SHA-256 with the published checksum.
2. Open the DMG and drag `YourMove.app` into Applications (or extract the ZIP with Finder and place the app in Applications).
3. Open the app. Because this build is **ad-hoc signed and not notarized**, macOS may block initial launch: choose **Done** (not Move to Trash), then use **System Settings → Privacy & Security → Open Anyway** for the per-app approval, and open the app again. Do **not** disable Gatekeeper globally or strip quarantine attributes.

If your Mac does not offer an individual approval path, or the app still cannot open, report the exact macOS message. Do not bypass system security.

## Local data and privacy

User data is stored by default under `~/Library/Application Support/YourMove`. With YourMove completely closed, back up the **entire directory**, including `jobs.db` and `resumes/`, not the database alone. In-progress employer-browser sessions are not resumed after app restart.

Actions that retrieve employer pages or request an external AI provider may transmit selected information. They are separate from normal local organization and should require the applicant's authorization.
