## Scope: what shipped

63 commits on the release line since the pre-release baseline, in five workstreams:

1. **React/TypeScript/Vite migration with Quiet Ink.** Opportunities, resume library, and the application workspace moved from Go templates to a strict-TS React frontend served in the same Wails 3 window; Go stays authoritative for validation, state, documents, and effects. Design tokens ported to `quiet-ink.css`.
2. **Application workspace.** Job preparation as guided activities (Review → Documents → Questions → Apply → Submission history): résumé selection with role-family routing and master-designation semantics, early/live application answers with explicit review-before-use, cover-letter drafts/generation with provider consent, employer-browser continuation with exact-scope authorization, and locally recorded submissions. No automatic employer submission anywhere.
3. **Career Evidence (shipped) vs. Discovery/Studio (parked).** Career Evidence records applicant-reviewed experiences and feeds cover letters. Career Discovery and Career Studio were built on this line, then hidden behind the `careerDiscoveryEnabled` flag for 0.1.0 — components, styles, handlers, and tests intact for a future version.
4. **Desktop UX rescue slice.** Documents became a two-column list-plus-action-rail layout (mirrored in Go templates); workspace orientation, next-step cues, and empty states rewritten in plain actionable language; blue edge treatments replaced with neutral Quiet Ink surfaces; AI Connections and Utilities become settings-style pages.
5. **Application-browser selector (enabled).** Was a disabled control backed by dead scaffolding. Now: `settings` table, single-owner preference read/write/resolve (env override preserved), session-factory wiring, Utilities GET/POST with honest per-engine availability (fixed Firefox cache-layout glob; Chromium follows the real system-binary resolution), WebKit excluded with reason.

## Defects found and fixed during qualification

- **Workspace crash on question-less jobs** (`questions: null` from Go crashed `/jobs/:id` entirely). Found by the cross-browser matrix; fixed at the fetch boundary with null-to-empty coercion.
- **Qualification drivers referenced renamed UI labels** (workspace tabs, Fill action). Updated; both engine journeys re-pass.
- **CI could not fetch the private `yourmove-career-discovery` module** (pre-existing branch-line condition since Oct 30). Fixed with a read-only `CAREER_DISCOVERY_READ_TOKEN` secret wired into both CI jobs; refrozen as build 3 and rebuilt.
- **`.webloc` cannot open the Privacy & Security pane URL** (Finder error -10400). Shipped as `.inetloc`, which opens via the browser's standard allow-prompt.

## How it was qualified (evidence, not claims)

- `prepare.sh` on the exact frozen tree: both Go suites, ad-hoc-signed bundle, ZIP/source packaging with checksums.
- Engine qualification (`qualification` tag, production build): full document-transfer journey passes on **chromium and firefox** — exact resume bytes, zero employer submissions, explicit-only submission recording, second opportunity reached.
- Browser matrix on identical synthetic data: Chrome stable 156 and Canary 159 render all key pages with zero console errors; Wails desktop verified by screenshot (dark mode included); Safari not verified (remote automation unavailable in the test session).
- Durability: `kill -9` restart byte-identical (resume bytes, hashes, letter, selection, preference); pre-`settings` migration tested; exports byte-identical.
- Negative paths: missing browser binary refuses cleanly with no session residue; invalid preference refused with explanation; unconfigured AI provider fails clearly with drafts untouched; generation without consent refused.
- Gatekeeper reality: `spctl` rejects the quarantined app; the genuine first-launch warning captured verbatim ("Move to Trash" is the default — the guide says choose Done); the Settings deep-link opens the Privacy & Security pane (3× verified); per-launch Open Anyway approval left to the clean-account pass.
- Installation docs rewritten with real screenshots; website CTA points at the DMG with the ZIP as alternative; all links verified live after deploy.
