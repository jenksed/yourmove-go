  passes under both `desktop` and `desktop,production`.

    `automatic updates disabled: no update manifest URL pinned (manual DMG
    remains available)`, starts normally for local work, never triggers the

  - dev (`-tags desktop`, same env): logs `automatic updates enabled`,
    honors the fixture channel. Evidence: `/tmp/ym-gui2/evidence/dev-probe.log`.
- Embedded ldflags pins (`updaterManifestURLEmbedded`,

## 6. Release blockers (S6; not development defects)

1. `release/macos/build.sh` still builds with `-ldflags '-s -w'` and no
   version/trust-root pins (finding F3, unchanged). S6 must require and
   inject `AppVersion`/`AppBuild` plus the production manifest URL and
   Ed25519 public key, and fail closed on plist/ldflags mismatch.
2. Developer ID signing, notarization, stapling, Gatekeeper acceptance.
3. Owner-approved production key; signed manifest publication through the
   approved channel; versioned DMG + updater ZIP distribution; normal
   `/Applications`, quarantine/downloaded-install, and read-only behavior;
   clean downloaded A→B acceptance with a notarized B.
4. Manual DMG fallback remains available (`build.sh` + `distribute.sh`,
   untouched by this work).

No production credentials were created, used, or needed.
